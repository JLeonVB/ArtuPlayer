# ArtuPlayer - Controlador MIDI para Linux

Sintetizador y grabadora MIDI en Python diseñado para Arturia MiniLab 3.

## Requisitos de Sistema (Linux/Ubuntu/Debian)
Antes de correr el script, necesitas instalar el motor de audio:
```bash
sudo apt-get update
sudo apt-get install python3-tk fluidsynth fluid-soundfont-gm build-essential libasound2-dev
